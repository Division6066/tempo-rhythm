# Contract — batch DRYRUN

Every backend function the DRYRUN component tickets call. NEW = built by TEMPO-DRYRUN-01 (the data
ticket). EXISTING = already in `convex/`. Components call only these names.
All functions require an authenticated user (`requireUser`) and only return the caller's own,
non-deleted rows.

## NEW (TEMPO-DRYRUN-01)

| Function | Args | Returns | Used by |
|---|---|---|---|
| `api.notes.listJournal` (convex/notes.ts) | `{periodType?: "daily"\|"weekly"\|"monthly"}` | `Doc<"notes">[]` (periodType ≠ "none", newest `updatedAt` first) | -02 |
| `api.search.global` (convex/search.ts) | `{query: string, limit?: number}` (limit default 5, max 20, per group) | `{tasks: {_id: Id<"tasks">, title: string, status: string}[], notes: {_id: Id<"notes">, title: string, snippet: string, periodType: string}[], habits: {_id: Id<"habits">, name: string}[], goals: {_id: Id<"goals">, title: string}[], routines: {_id: Id<"routines">, name: string}[]}` (empty query → all empty) | -03 |
| `api.routines.list` (convex/routines.ts) | `{}` | `{_id: Id<"routines">, name: string, habitCount: number, updatedAt: number}[]` | -04 |
| `api.routines.get` | `{routineId: Id<"routines">}` | `{_id: Id<"routines">, name: string, habits: {_id: Id<"habits">, name: string, cadence: "daily"\|"weekly", currentStreak: number}[]} \| null` (habits in stored order) | -05 |
| `api.routines.create` | `{name: string, habitIds: Id<"habits">[]}` | `Id<"routines">` | -04 |
| `api.routines.update` | `{routineId: Id<"routines">, name?: string, habitIds?: Id<"habits">[]}` | `Id<"routines">` | -05 |
| `api.routines.remove` | `{routineId: Id<"routines">}` | `{success: boolean}` (soft delete) | -04 |
| `api.rewards.getPebbles` (convex/rewards.ts) | `{}` | `{pebbles: number, longestStreak: number, daysToNextPebble: number}` (pebbles = Σ floor(longestStreak/7) over habits; assumption, the PRD gives no rate) | -06 |

New table: `routines` (userId, name, habitIds: Id<"habits">[], createdAt, updatedAt, deletedAt?;
indexes `by_userId`, `by_userId_deletedAt`).
